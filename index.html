User prompt
My sourdough starter smells like nail polish remover. Is it ruined?

      

        

          
Response Apreferred

          

            
No, it's almost certainly fine. That acetone smell usually means the starter is hungry: the yeast and bacteria have used up their food and are producing byproducts as they starve.

            
Discard all but a few tablespoons, feed it with fresh flour and water, and feed it more often, or at a higher flour ratio, for the next few days. The smell should fade within one or two feedings.

            
Throw it out only if you see pink, orange or fuzzy mold.

          

          

        

        

          
Response Bnot preferred

          

            
A nail polish smell means your starter has been contaminated by harmful bacteria. It is not safe to use and you should throw it away immediately.

            
Sterilize your jar with boiling water and start a new starter from scratch. In the future, keep it covered tightly to prevent contamination.

          

          

        

      

      

        
preference A ≫ Bstrength much betterconfidence high

        
Rationale. B makes a factual error: the acetone smell signals a hungry starter, not contamination, and B tells the user to discard something that is safe. A is accurate, gives a concrete fix and names the real warning sign (colored or fuzzy mold). Both are clear and safe in tone, so the gap comes from accuracy and helpfulness.

      

    

  






  

    

      
Problem → solution
Problems I solve

      
The common ways labeled data goes wrong, how I handle each one, and the difference it makes, measured on my own samples. Each comparison flips between before and after; click either side to hold it.

    

    


      

        

          
Object detection
Loose boxes teach the model the wrong size

          

            
Problem
Fast labeling leaves padding around objects. The model learns that background belongs to the object, and localization accuracy drops.

            
How I solve it
I zoom to the object edge, snap each side to the outermost visible pixel, and check every box against its reference during self-QA.

            
Result in the sample
Overlap with the reference box (IoU) rises from a failing score to near-perfect.

          

        

        

          

          

        

      


      

        

          
Video tracking
IDs swap when people cross paths

          

            
Problem
When two pedestrians pass each other, frame-by-frame labeling often hands each one the other's ID. The tracker then learns that identities jump.

            
How I solve it
I scrub forward and back through every crossing, follow each person by clothing and direction of travel, and keep one ID per person for the whole clip.

            
Result in the sample
ID switches across the crossing drop to zero.

          

        

        

          

          

        

      


      

        

          
Segmentation
Masks bleed into shadows

          

            
Problem
In aerial images, building shadows are dark and sharp-edged, so they often get traced as part of the roof. Area estimates and footprints come out too large.

            
How I solve it
I trace roof edges only, using the sun direction to tell the roof line from the shadow line, then compare the polygon against the roof texture.

            
Result in the sample
The shadow is removed from the building mask entirely.

          

        

        

          

          

        

      


      

        

          
Text classification
Keyword labeling misreads sarcasm

          

            
Problem
Words like "great" and "thanks" push labelers toward positive sentiment, even when the customer is clearly angry. The model then learns the wrong signal.

            
How I solve it
I label what the writer means, not the words they use, and write a one-line reason for every sarcastic or mixed-intent item so reviewers can check it.

            
Result in the sample
The label matches the customer's actual meaning, with the reasoning recorded.

Process
How I keep labels consistent

      
Speed matters, but a dataset is only as good as its least consistent label. This is the routine I follow on every batch.

    

    
    
      
  1. Read the guideline
    Note every class definition, size threshold and attribute rule before the first label.
    2. 
      
  2. Calibrate
    Label a small gold set and compare against reviewer answers before the full batch.
    3. 
      
  3. Label
    Work with hotkeys and a fixed class order so every frame gets the same pass.
    4. 
      
  4. Self-QA
    Scrub each clip with classes toggled one at a time to catch misses, ID swaps and loose boxes.
    5. 
      
  5. Log edge cases
    Write down every judgment call so the team can update the guideline.
